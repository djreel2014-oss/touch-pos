## What Touch POS is
A touch-screen point of sale for Windows 10 and 11. It is a single HTML page (src\app\index.html) that runs in its own window using the Edge engine built into Windows, and works offline. Data is stored by the page itself, with automatic daily backups and files saved to C:\ProgramData\TouchPOS\Files by default.

Main features: selling page with custom product layouts per staff member, several people on one order, supervised customers limited to one box item at a time with an override code, customer profiles with photos, QR and NFC credentials, Apple Wallet pass files (unsigned), receipts and PDFs, staff PINs and temporary PINs, idle lock, two-monitor customer display, import and export (JSON, ZIP with photos, CSV).

## Files in src
- app\index.html: the whole application, 1105 lines.
- app\lib\desktop-shim.js: file saving and a small PDF layer built on pdf-lib.
- installer_exe.ps1: installer script that Setup-TouchPOS.cmd runs; Setup is generated by putting this script before a base64 copy of the program files.
- Start-TouchPOS.cmd: runs the program without installing.
- Uninstall.cmd and uninstall.ps1: uninstaller.
- Fetch-Photos.cmd and fetch-photos.ps1: downloads customer pictures from web addresses in a CSV or JSON list.
- README.txt: the readme shipped with the program.
